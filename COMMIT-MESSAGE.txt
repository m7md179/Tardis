Complete TypeScript migration from Go

Major rewrite of TARDIS time tracking CLI from Go to TypeScript/Bun.

## Features

### Session Management
- Start, stop, pause, resume time tracking
- Multiple simultaneous sessions
- Duration calculation excluding pause time
- Status display and session listing

### Todoist Integration
- REST API v2 client
- Fuzzy task matching (exact, prefix, contains)
- Automatic time window extraction from descriptions
- Sync completed sessions back to Todoist
- Offline mode support

### Storage
- File-based JSON storage (~/.tardis/)
- Date-based session archiving
- Automatic Go data migration
- Session CRUD operations

### CLI Features
- 14 commands (start, stop, pause, resume, status, list, log, tasks, sync, complete, delete, wipe, setup, config)
- Interactive setup wizard
- Task picker for multiple matches
- Colored terminal output
- Progress spinners

## Technical Details

### Stack
- TypeScript 5.7 with strict mode
- Bun 1.3+ runtime
- Zod for schema validation
- Commander.js for CLI framework
- Monorepo with Turborepo

### Testing

- E2E, integration, and unit tests

### Documentation
- Complete installation guide

### CI/CD
- GitHub Actions workflow

## Migration Notes

- Automatic migration from Go session format
- PascalCase → camelCase field names
- Unix timestamps → ISO 8601 strings
- Backup created before migration

## Performance

- Binary size: <10MB target

- Bun runtime: 3x faster than Node.js

## Breaking Changes

- Config location: ~/.tardis/config.json (was ~/.tardis/)
